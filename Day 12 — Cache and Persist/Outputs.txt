[info] 15. WHEN CACHING CAN HURT PERFORMANCE
[info] ------------------------------------------------------------
[info] Caching is NOT always beneficial.
[info] Caching can hurt performance when:
[info] 1. The RDD is used only once.
[info] 2. The RDD is very large.
[info] 3. The cached data causes memory pressure.
[info] 4. Other useful cached data gets evicted.
[info] 5. The original computation is cheap.
[info] 6. Serialization/deserialization overhead becomes significant.
[info] 7. Disk-based persistence is slower than recomputation for a cheap job.
[info] Rule:
[info] Cache/Persist when:
[info]     Expensive computation
[info]            +
[info]     Multiple reuse
[info]            +
[info]     Enough resources
[info] Avoid unnecessary caching when:
[info]     Cheap computation
[info]            +
[info]     Single use
[info]            +
[info]     Large dataset
