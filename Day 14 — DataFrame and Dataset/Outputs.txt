[info] 20. RDD vs DATAFRAME vs DATASET
[info] ------------------------------------------------------------
[info] RDD
[info] ---
[info] Low-level distributed collection.
[info] Example:
[info]     RDD[Employee]
[info] Advantages:
[info]     - Fine-grained control
[info]     - Flexible object processing
[info] Disadvantages:
[info]     - Less structured
[info]     - Less optimization compared with DataFrame/Dataset APIs
[info] DataFrame
[info] ---------
[info] Distributed data organized into named columns.
[info] Conceptually:
[info]     Dataset[Row]
[info] Advantages:
[info]     - Schema
[info]     - SQL support
[info]     - Catalyst optimization
[info]     - Easy analytical operations
[info] Disadvantages:
[info]     - Columns are accessed more generically
[info]     - Less compile-time type safety than Dataset
[info] Dataset
[info] -------
[info] Strongly typed distributed collection.
[info] Example:
[info]     Dataset[Employee]
[info] Advantages:
[info]     - Compile-time type safety
[info]     - Case classes
[info]     - Functional transformations
[info]     - Catalyst optimization
[info]     - Encoder support
[info] Disadvantages:
[info]     - Scala-specific typed API
[info]     - Requires appropriate encoders
