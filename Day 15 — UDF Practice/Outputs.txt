[info] 25. BUILT-IN FUNCTION VS UDF
[info] ------------------------------------------------------------
[info] Built-in Spark function:
[info]     upper()
[info]     lower()
[info]     round()
[info]     abs()
[info]     sqrt()
[info]     when()
[info] Advantages:
[info]     - Implemented by Spark
[info]     - Optimized by Spark
[info]     - Usually preferred when available
[info]     - Better integration with Spark SQL execution
[info] UDF:
[info]     User Defined Function
[info] Example:
[info]     salary_band(transaction_amount)
[info] Advantages:
[info]     - Allows custom business logic
[info]     - Useful when no suitable built-in function exists
[info] Disadvantages:
[info]     - Can introduce serialization/execution overhead
[info]     - Spark has less visibility into arbitrary UDF logic
[info]     - Built-in functions are generally preferred when they
[info]       can express the same requirement
[info] 26. WHEN TO USE A UDF
[info] ------------------------------------------------------------
[info] Use a UDF when:
[info] 1. Business logic is custom.
[info] 2. No suitable built-in Spark function exists.
[info] 3. The transformation cannot be conveniently expressed using
[info]    Spark SQL/DataFrame functions.
[info] Example:
[info]     transaction_amount
[info]             |
[info]             v
[info]       custom business rule
[info]             |
[info]             v
[info]        Risk Category
[info] Avoid a UDF when an equivalent built-in Spark function exists.

[info] 28. IMPORTANT UDF CONCEPTS
[info] ------------------------------------------------------------
[info] UDF
[info] ---
[info] User Defined Function.
[info] Scala Function
[info] ---
[info] Normal Scala function written by the developer.
[info] Spark UDF
[info] ---
[info] A Spark-compatible wrapper around custom function logic.
[info] withColumn()
[info] ---
[info] Creates or replaces a DataFrame column.
[info] spark.udf.register()
[info] ---
[info] Registers a named UDF that can be used from Spark SQL.
[info] Built-in Function
[info] ---
[info] Function already provided by Spark.
[info] Catalyst
[info] ---
[info] Spark SQL optimizer that can optimize structured query plans.
[info] Important rule:
[info] ---
[info] Prefer built-in Spark functions when they can express the
[info] required transformation. Use UDFs when custom logic is needed.
