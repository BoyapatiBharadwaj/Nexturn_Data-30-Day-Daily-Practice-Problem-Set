[info] 2. WINDOW FUNCTION CONCEPT
[info] ================================================================================
[info] A window function performs a calculation across related rows
[info] without collapsing those rows into one row.
[info] Basic structure:
[info] Window
[info]   |
[info]   +-- partitionBy() -> divides rows into groups
[info]   +-- orderBy() -> defines order inside each group
[info] Example:
[info] Window
[info]   .partitionBy("course")
[info]   .orderBy(col("marks").desc)

[info] 23. WINDOW FUNCTIONS VS GROUP BY
[info] ================================================================================
[info] GROUP BY:
[info]   students
[info]       |
[info]       +---- GROUP BY course
[info]       |
[info]       v
[info]   one row per course
[info] WINDOW FUNCTION:
[info]   students
[info]       |
[info]       +---- PARTITION BY course
[info]       |
[info]       v
[info]   every original row is preserved
[info] Example:
[info] GROUP BY:
[info] course       average_marks
[info] --------------------------------
[info] Spark              89
[info] Kafka              84
[info] WINDOW:
[info] student     course      marks    avg_course_marks
[info] --------------------------------------------------
[info] Ananya      Spark        95           89
[info] Kavya       Spark        95           89
[info] ...
[info] The window function adds information to each row
[info] instead of collapsing rows.

[info] 26. DAY 17 VIVA SUMMARY
[info] ================================================================================
[info] Q1. What is a window function?
[info] A:
[info] A window function performs calculations across related rows
[info] while preserving the individual rows in the result.
[info] Q2. What does partitionBy do?
[info] A:
[info] It divides the dataset into independent groups for the
[info] window calculation.
[info] Q3. What does orderBy do inside Window?
[info] A:
[info] It defines the ordering of rows within each partition.
[info] Q4. Difference between row_number, rank and dense_rank?
[info] A:
[info] row_number gives every row a unique number.
[info] rank gives tied rows the same rank and leaves gaps.
[info] dense_rank gives tied rows the same rank without gaps.
[info] Q5. What is lag?
[info] A:
[info] lag accesses a value from a previous row.
[info] Q6. What is lead?
[info] A:
[info] lead accesses a value from a following row.
[info] Q7. How do you find the latest record per customer?
[info] A:
[info] Partition by customer, order by date descending,
[info] apply row_number and filter row_number = 1.
[info] Q8. How do you find top 3 students per course?
[info] A:
[info] Partition by course, order by marks descending,
[info] apply dense_rank and filter rank <= 3.
[info] Q9. When would you use row_number instead of dense_rank?
[info] A:
[info] When I need exactly 3 rows per group rather than all
[info] rows belonging to the top 3 ranks.
[info] Q10. Difference between GROUP BY and window functions?
[info] A:
[info] GROUP BY reduces multiple rows into groups.
[info] Window functions preserve the original rows and add
[info] calculated information to them.
