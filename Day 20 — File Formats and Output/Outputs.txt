[info] 9. FILE FORMAT COMPARISON
[info] ==========================================================================================
[info] CSV
[info] ---
[info] Text-based.
[info] Human-readable.
[info] Simple and widely supported.
[info] Does not store Spark schema in the same way as Parquet.
[info] JSON
[info] ----
[info] Semi-structured.
[info] Useful for nested and API-style data.
[info] Usually larger than columnar formats for analytics.
[info] PARQUET
[info] -------
[info] Columnar storage format.
[info] Stores schema information.
[info] Efficient for analytical queries.
[info] Supports column pruning and predicate pushdown.
[info] Commonly used in data lakes and lakehouses.

[info] 16. REPARTITION VS COALESCE
[info] ==========================================================================================
[info] repartition(N)
[info] ---------------
[info] Changes the number of partitions.
[info] Can increase or decrease partitions.
[info] Generally causes a shuffle.
[info] coalesce(N)
[info] -----------
[info] Primarily used to reduce partitions.
[info] Usually avoids a full shuffle.
[info] Example:
[info] 8 partitions
[info]     |
[info]     +-- repartition(4)
[info]     |       |
[info]     |       +--> shuffle
[info]     |
[info]     +-- coalesce(4)
[info]             |
[info]             +--> generally avoids full shuffle
