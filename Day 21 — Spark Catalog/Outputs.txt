[info] Q1. What is Spark Catalog?
[info] A:
[info] Spark Catalog provides an interface for discovering
[info] and managing databases, tables, views and metadata
[info] available to Spark.
[info] Q2. How do you list databases?
[info] A:
[info] spark.catalog.listDatabases()
[info] Q3. How do you list tables?
[info] A:
[info] spark.catalog.listTables()
[info] Q4. How do you create a temporary view?
[info] A:
[info] df.createOrReplaceTempView("view_name")
[info] Q5. How do you query a temporary view?
[info] A:
[info] spark.sql("SELECT * FROM view_name")
[info] Q6. What is a registered table?
[info] A:
[info] A table known to Spark's catalog and associated with
[info] table metadata and storage information.
[info] Q7. How do you inspect a table schema?
[info] A:
[info] DESCRIBE table_name
[info] or:
[info] df.printSchema()
[info] Q8. How do you inspect detailed table metadata?
[info] A:
[info] DESCRIBE EXTENDED table_name
[info] Q9. Difference between temporary view and table?
[info] A:
[info] A temporary view is scoped to the SparkSession and is
[info] not a persistent table. A registered table has catalog
[info] metadata and can reference persisted data.
[info] Q10. What is a global temporary view?
[info] A:
[info] A temporary view available across SparkSessions within
[info] the application through the global_temp database.
[info] Q11. How do you check whether a table exists?
[info] A:
[info] spark.catalog.tableExists("table_name")
[info] Q12. Why is a catalog important in data engineering?
[info] A:
[info] It provides metadata and discovery information so
[info] datasets can be organized and queried as databases,
[info] tables and views instead of treating every dataset
[info] only as an individual file path.
