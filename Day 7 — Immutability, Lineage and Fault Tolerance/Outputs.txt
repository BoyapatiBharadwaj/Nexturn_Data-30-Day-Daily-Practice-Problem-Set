[info] ------------------------------------------------------------
[info] Lineage is the record of transformations used to create an RDD.
[info] Spark uses lineage to recompute lost partitions.
[info] Lineage allows Spark to recover data without requiring
[info] every intermediate RDD to be permanently stored.

[info] 13. CONCEPTUAL EXECUTOR LOSS
[info] ------------------------------------------------------------
[info] Imagine the following situation:
[info] Executor 1 contains Partition 0.
[info] Executor 2 contains Partition 1.
[info] Suppose Executor 1 fails.
[info] Partition 0 is lost from Executor 1.
[info] Spark does NOT need to recompute the entire RDD.
[info] Spark uses lineage to recompute the lost Partition 0.
[info] Conceptually:
[info] Original RDD
[info]    +---- Partition 0 ---- Executor 1  X LOST
[info]    +---- Partition 1 ---- Executor 2  OK
[info]                  v
[info] Spark checks lineage
[info]                  v
[info] Recompute Partition 0
[info]                  v
[info] New executor processes Partition 0
[info] ------------------------------------------------------------
[info] 14. WHAT DOES SPARK RECOMPUTE?
[info] ------------------------------------------------------------
[info] Spark recomputes the lost partition.
[info] It starts from the required parent partition.
[info] It re-executes the transformations needed to recreate it.
[info] Example lineage:
[info] numberRDD
[info]     -> filter
[info]     -> map
[info]     -> filter
[info]     -> finalRDD
[info] If a finalRDD partition is lost,
[info] Spark can recompute the necessary parent partition
[info] through the transformation lineage.
[info] ------------------------------------------------------------
[info] 15. FAULT TOLERANCE
[info] ------------------------------------------------------------
[info] RDD fault tolerance is based on lineage.
[info] If a partition is lost:
[info] 1. Spark detects the missing partition.
[info] 2. Spark examines the RDD lineage.
[info] 3. Spark identifies the required parent partition.
[info] 4. Spark re-executes the necessary transformations.
[info] 5. The lost partition is recreated.
[info] ------------------------------------------------------------
[info] 16. CORE CONCEPT CONNECTION
[info] ------------------------------------------------------------
[info] RDD IMMUTABILITY:
[info] Transformations never modify an existing RDD.
[info] LINEAGE:
[info] Spark remembers how each RDD was derived.
[info] FAULT TOLERANCE:
[info] Spark uses lineage to recompute lost partitions.
[info] Therefore:
[info] IMMUTABILITY -> LINEAGE -> RECOVERY
